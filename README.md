This is an exercise project, the app features:
----------------------------
Client GUI App:
- app does support nicknames
- send messages either hitting 'enter' key or clicking 'send' button
----------------------------
Server Console App:
- sends messages history to every new client
- every recieved message will be broadcasted to all clients
- broadcasts greatings to new clients as well
----------------------------
Development environment:
QT framework 6.10.1 version
Visual Studio 2026
Microsoft Windows 11
